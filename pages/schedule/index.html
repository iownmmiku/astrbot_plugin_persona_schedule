01 / 生活与回复

启用角色日程

默认关闭。开启后，受控对话按日程回复。

02 / 有弹性的生活

让对话影响日程

最近还在聊天时，判断话题和活动的轻重，允许有限延后。

忙碌前自然打招呼

只向最近聊过的受控对话告知，每个时段最多一次。

开启弹性后，临近睡觉时的聊天会带上倦意，重要话题可让可调整的活动稍后开始。不会无限推迟，也不会延后锁定时段。判断使用日程生成模型；提前告知不会发给久未聊天的会话。需要启用角色日程并选择对话范围。

03 / 每日生活日记

跨日后自动写日记

需要启用角色日程。按角色时区，在当地日期结束后归档。

把白名单聊天写进回忆

参考当天实际采集的文字，保留角色自己的感受。

离线重启后，每次检查补一篇最近 7 天内缺失且有日程的日记。聊天素材只来自下方明确选择的白名单；即使控制所有聊天，也不会扩大日记采集范围。空名单时只按日程写。消息按角色、会话和当地日期隔离，只采集启用后的文本。超出篇数后在下次归档时清理较早日记。

04 / 提前安排每一天

主动生成当天日程

需要启用角色日程。不必等收到消息再安排生活。

选择 AstrBot 人设已选 0 个

使用每个角色自己的时区；未分析的人设先使用默认时区。同一角色每天共享一份日程，已有安排不会覆盖。启动时若已过设定时间，会补齐当天缺失的安排。

“所有已分析角色”只安排已有生活档案的角色。选择指定人设可提前为尚未分析的人设建立档案，首次生成会额外分析人设和年度活动。此范围独立于对话白名单。

05 / 随想画卷联动

主动回复遵循角色日程

默认关闭。安装随想画卷后，可开启联动。

忙碌

取消这次主动回复，不加入待回留言，也不在空闲后补发。

空闲 / 半忙

主动回复参考当前活动、时间与回复状态，让角色的近况保持连贯。

需要同时启用角色日程；只对纳入日程的对话生效。对话白名单仍然有效。

06 / 生活里的突发情况

让生活偶尔出现插曲

默认关闭。按人设生成临时事件，可能暂时忙碌或慢回。

每个角色每天抽签一次，默认 20%，最多发生一次。不同对话共享结果，刷新或重启不会重抽。没有合适时间或生成失败时跳过；已经抽签后的概率修改次日生效。

临时事件一般持续 15～60 分钟，保护锁定和固定职责；忙碌时静默，恢复后参考留言补回。日记与开启联动的随想画卷采用同一份实际安排。

07 / 模型调用与资源

0 表示不限。预算约束自动日记、预生成和突发等后台任务；补回留言与即时判断优先处理。达到额度时保留现有安排，详情可在运行诊断查看。

08 / 世界观与活动检索

09 / 对话控制范围

默认不控制任何聊天。日程和日记仍可独立生成。

指令不受作息影响，忙碌时也可以使用 /reset 等已注册指令。对话范围同时用于日程补回、提前告知和画卷联动。下方白名单还可独立限定日记的聊天素材。

同一聊天窗口切换对话记录仍属于同一会话。选择后需保存设置。空白名单不会控制任何聊天，也不会提供日记聊天素材。
