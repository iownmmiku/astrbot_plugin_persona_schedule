SYSTEM / CONFIGURATION

运行控制

设置回复节奏、生成模型，以及参与日程的对话。

01 / 生活与回复

启用角色日程

默认关闭。开启后，受控对话按日程回复。

02 / 有弹性的生活

让对话影响日程

最近还在聊天时，判断话题和活动的轻重，允许有限延后。

忙碌前自然打招呼

只向最近聊过的受控对话告知，每个时段最多一次。

开启弹性后，临近睡觉时的聊天会带上倦意，重要话题可让可调整的活动稍后开始。不会无限推迟，也不会延后锁定时段。判断使用日程生成模型；提前告知不会发给久未聊天的会话。需要启用角色日程并选择对话范围。

03 / 每日生活日记

跨日后自动写日记

需要启用角色日程。按角色时区，在当地日期结束后归档。

离线重启后，每次检查为每个人设补一篇最近 7 天内缺失的日记。只使用已保存的日程，不虚构缺失日期，不读取聊天记录；白名单仅控制聊天回复，不限制日记归档。超出篇数后在下次归档时清理较早日记。

04 / 提前安排每一天

主动生成当天日程

需要启用角色日程。不必等收到消息再安排生活。

选择 AstrBot 人设已选 0 个

使用每个角色自己的时区；未分析的人设先使用默认时区。同一角色每天共享一份日程，已有安排不会覆盖。启动时若已过设定时间，会补齐当天缺失的安排。

“所有已分析角色”只安排已有生活档案的角色。选择指定人设可提前为尚未分析的人设建立档案，首次生成会额外分析人设和年度活动。此范围独立于对话白名单。

05 / 随想画卷联动

主动回复遵循角色日程

默认关闭。安装随想画卷后，可开启联动。

忙碌

取消这次主动回复，不加入待回留言，也不在空闲后补发。

空闲 / 半忙

主动回复参考当前活动、时间与回复状态，让角色的近况保持连贯。

需要同时启用角色日程；只对纳入日程的对话生效。对话白名单仍然有效。

06 / 世界观与活动检索

联网查找节日与原作活动

使用 Tavily，检索世界名、身份和文化关键词。

07 / 对话控制范围

默认不控制任何聊天。日程和日记仍可独立生成。

指令不受作息影响，忙碌时也可以使用 /reset 等已注册指令。对话范围同时用于日程补回、提前告知和画卷联动。

同一聊天窗口切换对话记录仍属于同一会话。选择后需保存设置。空白名单不会控制任何聊天。
